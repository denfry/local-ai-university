### Added

- Initial architecture scaffold: package layout under `src/aiu/` with
  documented (but unimplemented) responsibilities for `cli`, `config`,
  `llm`, `agents`, `curriculum`, `mastery`, `memory`, `web`, `sandbox`,
  `obsidian`, and `db`.
- Prompt templates for the Teacher, Student, Critic, Examiner, curriculum
  planning, and source evaluator roles.
- Project documentation: architecture, curriculum, mastery, Obsidian
  integration, security, web research, and development guide.
- Packaging (`pyproject.toml`), configuration examples (`.env.example`,
  `config.example.toml`), CI workflow, and open-source project files
  (license, contributing guide, code of conduct, security policy, issue
  and PR templates).
